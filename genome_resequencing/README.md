# Welcome to the _Genome resequencing_ project!
Here you will find the code to curate, annotate and compare bacterial genomes that was used to study an *Apilactobacillus kunkeei* strain that showed different phenotypes depending on the isolate.

## Additional Info
The folder ``analysis`` contains the assemblies in fasta and fastq format.<br>
The folder ``rawdata`` contains all the reads in bam format.<br>
The folder ``subreads`` contains the subreads in fastq format (one file per sample).<br>
The folder ``reports`` contains the run-reports.
